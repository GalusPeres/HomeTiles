# HomeTiles v0.6.11

Faster popups, more consistent dashboard rendering, and browser USB tools that stay connected while you browse the documentation.

## Highlights

- **Faster popups** — Shared popup frames and cached content reduce rebuilding. Corrected press handling removes unnecessary layout work, including the noticeable delay on large Weather tiles.
- **Stable media covers** — The current cover remains visible while its replacement loads or fails. Track changes no longer make the cover and text layout jump back and forth.
- **Consistent Weather tiles** — Values align with Sensor tiles and keep their top position on larger tiles, with forecasts below. Previews, two-line titles and text truncation follow the shared layout.
- **Correct PIN titles** — Protected tiles show their own unlock prompt: Radio displays Radio instead of the preloaded Settings title. The fix is shared across P4 and S3.
- **Browser device logs** — Read, copy and clear USB serial logs directly in desktop Chrome or Edge. A bounded log snapshot survives a page reload.
- **Continuous USB sessions** — Logger and flasher stay connected during internal navigation, search and back/forward. The header shows activity and flash progress; cancelling the port chooser leaves logging running.

## Update Notes

- **Bridge:** v0.6.44 or newer. No new Bridge release is required; existing layouts and configurations remain compatible.
- **Firmware:** use the regular `.bin` for OTA or **Update**. Use `_factory.bin` for first installation or an intentional factory reset. There are 15 device profiles with both images available.
- **Browser tools:** internal page navigation preserves USB. A full reload restores captured text but requires reconnecting for live logs.

Choose the exact board and revision. Camera remains experimental and P4-only. See [device support](https://galusperes.github.io/#device-support) for revision requirements.

## Hardware Confirmed

Shared UI improvements were tested on **Waveshare 8-inch, Waveshare 4B, Guition ESP32-4848S040 S3 and M5Stack Tab5**. The large Weather tile fix was confirmed on 8-inch; the final PIN title fix on Tab5.

## Pending Hardware Validation

All 15 release profiles built successfully. Other boards, exact revisions and longer runtime testing still need community feedback.
