# HomeTiles v0.6.11

Faster popups, stable media covers and improved browser USB tools.

## Highlights

- Faster popup opening, including large Weather tiles.
- Media covers stay visible during track changes and updates.
- Consistent Weather alignment, previews and title truncation.
- Correct unlock titles for PIN-protected tiles.
- New browser logger; logger and flasher stay connected while browsing the docs.

## Update Notes

Use **Bridge v0.6.44+**. Existing layouts remain compatible.

**Update:** regular `.bin`. **First installation / factory reset:** `_factory.bin`. Select your exact board and revision.

## Hardware Confirmed

UI fixes tested on **Waveshare 8-inch, Waveshare 4B, Guition ESP32-4848S040 S3 and M5Stack Tab5**. Final PIN fix confirmed on Tab5.

## Pending Hardware Validation

All 15 profiles built successfully; other boards and extended testing remain pending. See [device support](https://galusperes.github.io/#device-support).

Thanks to everyone testing and reporting issues.
