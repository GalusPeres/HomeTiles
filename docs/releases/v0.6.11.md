# HomeTiles v0.6.11

HomeTiles v0.6.11 improves popup responsiveness, fixes dashboard rendering and unlock titles, and adds browser device logs with persistent USB sessions across documentation pages.

## Highlights

### Faster popup opening

Popups reuse a shared frame, header and close button with cached content.

- Expensive content can follow the first visible frame.
- Tile press styles no longer trigger unnecessary descendant layout work, addressing the pronounced opening delay on large Weather tiles and improving other tile sizes too.

### Stable media artwork

Loaded covers remain visible while a replacement is pending or fails.

- Cover replacement keeps image data and URLs paired, avoiding unnecessary downloads and stale results.
- Media text keeps its layout while the next cover arrives.

### Weather matches the dashboard

Weather uses the shared tile input behavior, Sensor-aligned values and consistent preview headers.

- Values retain their top position on larger tiles, with forecasts below.
- Long and two-line Weather titles use the shared truncation logic.

### Correct PIN popup titles

Reopening a protected tile updates the complete title, so Radio shows its own unlock prompt instead of the preloaded Settings title.

- The correction is shared by P4 and S3 devices.

### Online device logs

Read USB serial logs directly from the documentation, copy or clear them, and recover the bounded log snapshot after reloading the page.

- The logger uses Web Serial in supported desktop Chromium browsers.

### Browse without disconnecting

Installer and logger sessions survive internal documentation navigation, including search and browser back/forward.

- A persistent header indicator shows the active USB operation and flash progress.
- The installer and logger coordinate ownership of the serial port; cancelling the device chooser leaves logging running.

### Regression coverage

98 automated tests cover native LVGL interaction and title reuse, Weather rendering, Web Admin previews, serial ownership and real documentation navigation.


## Update Notes

### Bridge and compatibility

Use **HomeTiles Bridge v0.6.44 or newer** for the complete feature set. No new Bridge release is required for this update. Existing layouts and configurations remain compatible.

### Firmware images

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for first installation or an intentional factory reset. The release provides 15 exact installer profiles, each with an OTA and factory image.

### Board and revision

Select the exact board and revision. Waveshare S3 LCD-4 requires **Rev 4.0**. Waveshare 7B/7B-C has separate pre-v3 and experimental exact ESP32-P4 v3.1 images; v3.2 and newer remain unsupported by the pinned toolchain. Camera remains experimental and ESP32-P4-only.

### Browser connection

The browser logger requires a compatible browser and an explicit USB connection. A full page reload restores captured text but requires reconnecting to resume live logging. Internal documentation navigation preserves the active connection.

## Hardware Confirmed

- The maintainer confirmed the popup and Weather responsiveness fixes on **Waveshare Touch LCD 8-inch**, including the previously slow large Weather tile, and confirmed corrected Weather title truncation.
- The maintainer confirmed the subsequent shared UI builds work well on **Guition ESP32-4848S040 S3**, **Waveshare Touch LCD 4B** and **M5Stack Tab5**.
- The final PIN title correction was confirmed on **M5Stack Tab5**. It uses the shared implementation; native tests also exercise the S3 and 4B layouts.
- The maintainer tested the documentation changes locally, including browser flashing. Automated browser tests additionally cover retained sessions and USB handoff with simulated hardware transport.

## Pending Hardware Validation

The release workflow builds and verifies every image. Compilation and native/browser tests do not establish physical behavior on every board. Community testing remains needed on the other profiles and exact revisions, and for longer navigation, media artwork, sleep/wake and camera sessions.

Existing device-specific validation limits remain in the [device support notes](https://galusperes.github.io/#device-support). In particular, Waveshare S3 GitHub OTA, exact-v3.1 hardware, the previously reported isolated S3 screensaver freeze and the external MQTT issue #37 still await their respective field confirmations.

Thanks to everyone testing HomeTiles on their devices and reporting reproducible differences in layout and responsiveness.
