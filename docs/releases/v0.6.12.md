# HomeTiles v0.6.12

v0.6.12 accelerates the Guition JC8012P4A1 V1/V2 interface and corrects Weather forecast positioning and daily temperature labels.

## Highlights

- Enabled PPA hardware rotation for larger ordinary UI updates on Guition JC8012P4A1 V1 and V2. These updates previously rotated on the CPU even when PPA was initialized. Small regions retain the CPU fallback, with shared timeout and recovery handling.
- Aligned the Weather forecast row on both Guition revisions with the existing Waveshare 8-inch and 10.1-inch position. All four profiles share the same 1280x800 grid; the Guition forecast was 10 pixels too low.
- Preserved the weather provider's daily minimum and maximum when hourly data covers only part of the day. Partial hourly forecasts no longer replace the full-day temperature labels.
- Improved browser USB log instructions and cleared stale flashing results when starting a new session.

## Update Notes

Use **HomeTiles Bridge v0.6.44 or newer** for the complete feature set. No new Bridge release is required. Existing layouts and configurations remain compatible.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for first installation or an intentional factory reset. Select the exact board and revision: Guition JC8012P4A1 V1 and V2 require different images.

The V1-specific ESP-Hosted network mitigation is preserved. This release does not change the Guition SD implementation or the Waveshare 8-inch display driver.

## Hardware Confirmed

The maintainer confirmed that the PPA correction resolves the reported slow interface on Guition JC8012P4A1 V2. The maintainer also reports working SD-card access with the existing SD implementation.

## Pending Hardware Validation

The corresponding V1 acceleration and forecast-position correction still need testing on an actual V1 device. Host regression tests cover both rotation directions, PPA/CPU fallback, timeout ownership and recovery, and matching forecast coordinates across all 35 supported tile spans. These tests and successful firmware compilation do not establish physical V1 behavior.

The daily temperature-label correction has focused regression coverage; broader provider and device feedback remains welcome. The SD-card reboot reported in issue #38 is not reproduced on the maintainer's V2 and is not claimed fixed here. Existing camera, networking and exact-revision limitations remain in the [device support notes](https://galusperes.github.io/#device-support).

Thanks to everyone testing HomeTiles, including the contributors who provided the original V2 panel data and reported the Weather problems.
