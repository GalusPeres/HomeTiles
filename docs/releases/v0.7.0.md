# HomeTiles v0.7.0

v0.7.0 adds half-size tiles, color rules and built-in cameras for Home Assistant.

## Highlights

- Tiles can be placed and resized in half steps, and many tile types can be half height.
- Corner radius, icon circles and tile colors are adjustable. With rules, icon and tile change color by value or state, take the entity's own color, or follow another entity.
- ESP32-P4 displays with a camera can share it with Home Assistant. The camera is off by default and remains experimental.
- Sensor and Energy graphs show the value under your finger. Climate shows all fan and swing modes that Home Assistant provides.
- Folders stay fast after long uptime, because processed updates now release their memory.
- New profiles for the Guition JC4880P443 (portrait) and for Waveshare 10.1 boards with ESP32-P4 v3.1 or newer.
- Fixes for Guition V2 touch and SD card, Tab5 wake brightness, the Wi-Fi list and the screensaver image list.

## Update Notes

Update to **[HomeTiles Bridge v0.7.0](https://github.com/GalusPeres/HomeTiles-Bridge/releases/tag/v0.7.0)** first and export your dashboard in Web Admin under **Import / Export** before updating.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision.

S3 displays can fail to update through the device from v0.6.12 or from the first v0.7.0 build. Install the regular `.bin` once through Web Admin; later device updates use the corrected updater.

To go back to v0.6.x, make every tile whole-size first, see [Going back to v0.6.x](https://galusperes.github.io/updating/#going-back-to-v06x).

## Hardware Confirmed

The maintainer tested this release on M5Stack Tab5, Waveshare LCD-4B and LCD-8, Guition JC8012P4A1 V2 and Guition ESP32-4848S040 (S3), including a full GitHub update on the S3. Built-in cameras were tested on Guition V2, Waveshare LCD-8 and Tab5.
