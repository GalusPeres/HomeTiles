# HomeTiles v0.8.0

v0.8.0 adds Lock, Alarm Panel and Fan tiles, an optional Web Admin password with encrypted commands, a redesigned Switch tile, and French and Polish.

## Highlights

- **Lock, Alarm Panel and Fan tiles** with their own popups. Locks and alarm panels open a code entry when Home Assistant needs a code and show only the states the device reports. They can be operated only from a display with encrypted commands and a Web Admin password.
- **Web Admin password:** optional; protects every page and API request. Saved Wi-Fi and MQTT passwords and PINs are no longer shown in the browser.
- **Encrypted commands:** pair the display with the Bridge by comparing a six-digit number. The Bridge then runs only commands the display encrypted and signed.
- **Redesigned Switch tile:** a dimmer or switch bar across the tile (Automatic, Dimmer, Switch or Icon button), paced like Home Assistant. Cover tiles get a position bar, Climate tiles a layout choice, and almost every tile type a half-height layout.
- **French and Polish:** two new languages. The keyboard follows the language: AZERTY for French, QWERTY for Polish, with their letters behind the keyboard key. The Polish translation comes from majki09.
- **Weather:** filled, colored icons, a tile tint that follows the weather, and moon icons at night with Bridge v0.8.0.
- **Complete graphs:** with Bridge v0.8.0, sensor graphs use Home Assistant's statistics and show the full seven days, also for busy sensors.
- **Faster Web Admin:** moving or editing a tile shows on the display almost at the same time as in the browser, only changed tiles are redrawn, and folder tabs load in the background. The previews match the device, and a dashboard import checks the whole layout before it changes anything.
- **Cameras:** camera popups play at up to 30 pictures per second, and displays showing the same camera share one stream. The built-in cameras' auto exposure regulates in small, gliding steps without swinging.
- **Performance and memory:** LVGL 9.6 recolors much faster (on the S3 from 230 to 5 ms), each image needs about 300 KB less flash, and tile state moved from internal RAM to PSRAM, leaving more room for folders and popups. Wi-Fi joins the strongest access point at full power.
- **No more blue flash:** ESP32-P4 displays keep their picture while settings are saved.
- **New boards:** Guition JC8012P4A1 V3 and Waveshare 7B/7B-C with ESP32-P4 v3.x get their own images, and the browser installer flashes ESP32-P4 v3.x boards and restarts every board afterwards.
- **Polish everywhere:** circles and controls sit one step above the tile, Media tiles take their color from the album cover, the PIN keypad is redesigned and protected folders show a lock, unknown Climate, Cover and Media entities are grey, popups open faster, and tiles take new states right away. Among many fixes: the Waveshare S3-Touch-LCD-4B drives its panel at 10 MHz against a shifted image, the Guition V2 keeps running when its microSD card cannot be mounted, and Media tiles drop an old cover when the player has no artwork.

## Update Notes

Update to **[HomeTiles Bridge v0.8.0](https://github.com/GalusPeres/HomeTiles-Bridge/releases/tag/v0.8.0)** first and export your dashboard in Web Admin under **Import / Export** before updating.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision.

Waveshare 7B panels on ESP32-P4 v3.1 that run the former v3.1-only image need one browser installer **Update** with the new 7B v3 image; that image now covers v3.1 and newer.

## Hardware Confirmed

The maintainer tested this release's features on M5Stack Tab5, Waveshare LCD-4B and LCD-8, Guition JC8012P4A1 V2 and Guition ESP32-4848S040 (S3), including the Lock, Alarm Panel and Fan tiles. Built-in cameras were tested on Guition V2, Waveshare LCD-8 and Tab5; French and Polish on Guition V2 and S3.

The Guition JC8012P4A1 V3 and Waveshare 7B v3 images, the Waveshare S3-Touch-LCD-4B panel clock, the Guition V2 microSD handling, and built-in cameras on the other P4 camera boards still need field feedback. See the [device support notes](https://galusperes.github.io/#device-support).
