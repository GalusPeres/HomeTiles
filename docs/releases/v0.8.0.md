# HomeTiles v0.8.0

v0.8.0 polishes HomeTiles throughout: smoother operation, a refined design and many bug fixes. It also adds Lock, Alarm Panel and Fan tiles, a Web Admin password with encrypted commands, a redesigned Switch tile, and French and Polish.

## Highlights

- New Lock, Alarm Panel and Fan tiles. Locks and alarm panels need encrypted commands and a Web Admin password.
- An optional Web Admin password protects the Web Admin. Commands to the Bridge can be encrypted; pairing compares a six-digit number.
- The Switch tile has a dimmer or switch bar. Cover and Climate tiles got new layouts, and almost every tile can be half height.
- French and Polish, with their letters on the keyboard.
- Faster everywhere: LVGL 9.6, about 300 KB less flash, more free RAM, quicker popups and screensaver, and Web Admin edits that show on the display almost at once.
- Camera popups at up to 30 FPS, smoother auto exposure for built-in cameras, and no more blue flash on ESP32-P4 displays while saving.
- Colored weather icons with night icons, and 7-day graphs that load much faster with Bridge v0.8.0.
- New images for the Guition JC8012P4A1 V3 and the Waveshare 7B with ESP32-P4 v3.x.
- Many fixes and polish, including the S3-Touch-LCD-4B image shift, Guition V2 microSD restarts and old Media covers.

## Update Notes

Update to **[HomeTiles Bridge v0.8.0](https://github.com/GalusPeres/HomeTiles-Bridge/releases/tag/v0.8.0)** first and export your dashboard in Web Admin under **Import / Export** before updating.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision.

Waveshare 7B panels running the former v3.1-only image need one browser installer **Update** with the new 7B v3 image.

## Hardware Confirmed

The maintainer tested this release on M5Stack Tab5, Waveshare LCD-4B and LCD-8, Guition JC8012P4A1 V2 and Guition ESP32-4848S040 (S3), including the Lock, Alarm Panel and Fan tiles. Built-in cameras were tested on Guition V2, Waveshare LCD-8 and Tab5.

## Pending Hardware Validation

The Guition JC8012P4A1 V3 and Waveshare 7B v3 images, the Waveshare S3-Touch-LCD-4B fix, the Guition V2 microSD handling, and built-in cameras on the other P4 boards still need field feedback. See the [device support notes](https://galusperes.github.io/#device-support).
