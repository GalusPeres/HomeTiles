# HomeTiles v0.9.3

v0.9.3 adds Czech, Slovak and Spanish, shows the icon file on the System page and adds two new displays.

## Highlights

- New languages: Czech, Slovak and Spanish. Choose them under **Localization** on the display or in the Web Admin.
- Keyboard: every language brings its own letters to the accent key, and holding a letter offers its accented forms with the language's own first. Czech and Slovak type on QWERTZ; Spanish has ñ, ¿ and ¡.
- Long dates follow the language, also with the year: "21 de agosto de 2026" in Spanish, "21. srpna 2026" in Czech.
- Icons card on the Web Admin **System** page: it shows whether the icon file with all 7447 icons is on the display, links the right file for the display, downloads it with **Update**, and installs a file uploaded by hand for networks that block the display's own download (#112). Factory images now contain the icon file, so a freshly flashed display shows every icon at once.
- New displays, not tested on hardware yet: Golden Security GS-T3E v2 (#93) and Waveshare ESP32-P4-WIFI6-Touch-LCD-5 (#76), the 5-inch with the voice assistant and the optional OV5647 camera.

## Update Notes

HomeTiles Bridge v0.9.2 stays current; nothing changes in Home Assistant.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision. The Waveshare LCD-5 has two images: one for ESP32-P4 before v3.0 and an experimental one for v3.1 or newer.

## Hardware Confirmed

The maintainer tested the Icons card (download, **Update** and upload by hand) on Guition JC8012P4A1 V2 and Guition ESP32-4848S040, and a factory image with the icon file on the Waveshare LCD-8.

## Pending Hardware Validation

The Golden Security GS-T3E v2 and the Waveshare LCD-5 are built from public documentation (openHASP and ESPHome configurations, Waveshare's BSP and examples) and are not tested on hardware yet. The Czech, Slovak and Spanish texts were checked against English, but not yet read by native speakers on a display; please report anything that reads wrong. The other boards need field feedback as before. See the [device support notes](https://galusperes.github.io/#device-support).
