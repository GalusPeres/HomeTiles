# HomeTiles v0.9.5

v0.9.5 fixes an empty media popup after a song change while its menu was open.

## Highlights

- Media popup: when a new song started while the menu (Speakers, Source or Library) was open, its cover could change the card's color, and after closing the menu the popup showed only its head and the **⋯** button. The player now stays visible; until this update, a restart or the next song with another cover brought it back.

## Update Notes

HomeTiles Bridge v0.9.4 stays current; nothing changes in Home Assistant.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision.

## Hardware Confirmed

The maintainer confirmed the fix on the Guition JC8012P4A1 V2.
